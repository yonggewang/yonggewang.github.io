  • Privacy Preserving Database Application Testing
    PI and coPIs: Dr. Xintao Wu, Dr. Yongge Wang, and Dr. Yuliang Zheng
    Supported by: NSF CCR-0310974
    Period:Sep 15, 2003 to Sep 14, 2005
    Amount:US$200000
    Project homepage
    Abstract: Government agencies and private organizations are accumulating a vast amount of sensitive information on citizens. These organizations often develop new applications to utilize the information stored in the databases. An essential phase of developing such a new application is to test it thoroughly prior to deployment.

    Traditionally, application developers carry out tests on their local development databases. A major shortcoming of this approach is that these local databases usually have only a small number of data samples and hence cannot simulate satisfactorily a live environment. On the other hand, the practice of testing applications against live production databases is becoming increasingly undesirable due to the fact that such use of live production databases may disclose sensitive data to an unauthorized tester and incorrectly update the underlying databases.

    This project investigates techniques to generate mock databases for application software testing without revealing any confidential information on the live production databases. Cryptographic techniques such as indistinguishability will be used to model privacy preservation as well as the degree of similarity between a live and a mock database. Success of the project will open up a new approach to secure application software testing and produce a prototype system for future deployment.

  • Security for storage area networks
    PI and coPIs: Yongge Wang
    Supported by:
    Period:
    Amount:
    Abstract: This project will analyze the survivability requirements for data storage networks and design security mechanisms for storage networks, addressing the critical data storage needs of a highly-connected, IT-enabled society that requires faster, more accessible transactions. Most existing storage networks have been built within organizations and could be considered bounded networks; these reliable storage networks work fine but they are not survivable, meaning that they do not provide essential services in the presence of attacks and failures, and they are not scalable. Current research on storage networks has focused mainly on improving performance and reliability, with little research on security and survivability issues. The survivability of storage networks against malicious attacks, such as cyber-terrorism, has been poorly addressed. The research of this project will concentrate on the security mechanism design for SAN (including iSCSI-based SAN and FC-based SAN), NAS, and DAS.
  • Survivable and globally-accessible storage services
    PI and coPIs: Yongge Wang
    Supported by:
    Period:
    Amount:
    Abstract: This research will focus on the design of scalable, survivable, and global networked storage services which meet the storage system requirements for both classical applications and new revolutionary applications. Similar topics are being extensively researched by other academic and industrial researchers in the context of peer-to-peer (P2P) systems. For a survivable storage service, the model and underlying assumptions are quite different from P2P systems, thus new mechanisms need to be designed. We have proposed several models and mechanisms for "survivable and globally-accessible storage services". In this research, we will test our model in a simulated network for all kinds of requirements and against all different attacks. We will improve our models and algorithms from the experimental results.
  • Secure communications in new environments
    PI and coPIs: Yongge Wang
    Supported by:
    Period:
    Amount:
    Abstract: Secure communication has been extensively studied in symmetric models. By symmetric, we mean that participating entities have similar power in communication. With the appearance of new technologies such as constraint wireless devices, this symmetric assumption is no longer valid. Thus new models for secure communications should be built (e.g., taking into consideration of jamming attacks and asymmetric communication powers) and new protocols for secure communication in distributed environment should be designed. This project will concentrate on the design of new communication models and on the design of new secure communication protocols.
